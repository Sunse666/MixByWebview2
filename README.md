# Mix

基于 Tauri 2 + WebView2 的 Chromium 内核浏览器

## 快速开始

1. 解压 `Mix-0.4.0-release.zip`（`dist/` 里按版本号命名）到任意目录
2. 双击 `mix.exe`
3. 首次启动会在同目录生成 `UserData/`、`crx/`、`javascript/`

程序目录不可写时（例如放在 `Program Files` 下），`UserData/` 会回落到系统用户目录，启动日志第一行会写明实际路径。

## 目录结构

```
Mix/
├── mix.exe
├── UserData/
│   ├── settings.json   设置
│   ├── history.json    历史
│   ├── bookmarks.json  书签
│   ├── favicons.json   网站图标映射
│   ├── favicons/       图标本地缓存
│   ├── session.json    上次的窗口与标签
│   ├── theme.json      主题
│   ├── custom.css      自定义样式
│   ├── downloads.json  下载记录（无痕下载不写入）
│   ├── permissions.json 站点权限决定
│   ├── zoom.json       按站点缩放
│   └── logs/mix.log    运行日志
├── crx/                扩展文件夹
└── javascript/         用户脚本
```

**备份**：设置 → 备份 → 导出配置，把 `UserData/` 里的设置、历史、书签、主题、图标、权限与下载记录打包，同时带上 `crx/`（扩展）和 `javascript/`（用户脚本）——这三样一起拷到新机器就能完整还原。不包含 WebView2 的 `profile/`（登录态与 Cookie）、`logs/`、`downloads/` 和扩展解包缓存。

## 功能

**浏览**
- 多标签 / 多窗口 / 无痕模式
- 标签分组（Ctrl+Shift+G）、固定标签、撤销关闭（Ctrl+Shift+T）
- 标签搜索（Ctrl+Shift+A）、悬停预览缩略图
- 后台标签挂起（省内存）与冻结，白名单域名不挂起
- 侧边栏（书签 / 下载 / 历史，可放左或右）
- 会话恢复、全屏、页内查找

**数据**
- 历史：分组、搜索建议、按站点筛选、图标持久化
- 书签：文件夹分类、双击改名、拖拽排序
- 下载：列表、打开

**扩展**
- 把解压好的扩展文件夹放进 `crx/`
- 扩展页可查看 WebView2 真实的加载状态、启用/停用

**界面**
- 内部页面：新标签页、历史、书签、下载、扩展、设置、用户脚本
- 命令面板：Ctrl+Shift+P（搜索动作与历史站点）
- 主题：9 个颜色 + 圆角/字号，支持实时预览与导入导出
- 页内翻译：点工具栏的「文」原地替换正文，再点一次还原原文（失败会在右上角提示）
- 中英双语（设置 → 语言）

**系统**
- 注册为默认浏览器
- 配置备份/恢复、自定义样式、自定义搜索引擎

## 鼠标手势

按住**右键**划动，松开执行。默认映射：

| 手势 | 动作 |
|---|---|
| ← / → | 后退 / 前进 |
| ↑ / ↓ | 滚动到顶 / 到底 |
| ↑↓ | 刷新 |
| ↓↑ | 恢复关闭的标签 |
| ←→ / →← | 下一个 / 上一个标签 |
| ↑→ | 新建标签 |
| ↓← | 关闭标签 |
| ↑← | 收藏 |
| ↓→ | 下载 |

**设置 → 鼠标手势** 可改颜色、线宽、阈值、每个手势的动作、以及禁用域名。改完对新打开的页面生效。

## 超级拖拽

| ↓ | 下载目标 |

## 右键菜单

菜单按点击的上下文分组，键位标在右侧（返回 / 前进为 `Alt+←` / `Alt+→`，书签 `Ctrl+D`，打印 `Ctrl+P`，源代码 `Ctrl+U`）：

| 分组 | 项 |
| --- | --- |
| 链接 | 在新标签中打开、复制链接地址 |
| 图片 | 在新标签中打开、复制图片地址、另存为（存图片本身）、用 Google 搜索这张图片 |
| 选中文字 | 复制、翻译选中内容 |
| 页面 | 返回、前进、重新加载、添加书签、打印、另存为（存页面文档）、翻译本页、在阅读模式下打开、为此页面创建二维码、查看网页源代码、检查 |

**另存为**：保存的是当前页面渲染后的文档，不是服务器返回的原始 HTML——对客户端渲染的页面，后者几乎是空的。所以存下来的文件不含外链样式和脚本，用浏览器打开会缺样式。

**阅读模式**：在页面里按「正文文字多、链接占比低」挑出主体，去掉导航和侧栏，按 34em 行宽重排。**这是启发式的**：新闻、博客、文档站通常准确，交互密集的页面可能抓错区域。

**会向外发请求的两项**：翻译把正文发给 `cn.bing.com`（Microsoft 翻译）；「用 Google 搜索这张图片」把图片地址发给 Google。其余各项都在本机完成。

## 扩展与用户脚本

**扩展**：解压后的文件夹放进 `crx/`，扩展页会显示。支持 MV3。

**用户脚本**：`javascript/` 里放 `*.user.js`，支持 `@name` / `@match` / `@run-at`。用户脚本页可启用/停用。

## 自定义

**主题**：设置 → 主题文件，改颜色、圆角、字号，可导出 `theme.json` 分享。

**自定义样式**：设置 → 外观 → 编辑自定义样式，写 CSS 会应用到所有网页（新打开的页面生效，已开的标签刷新一次即可）。

```css
/* 去掉 B 站首页的推荐位 */
.bili-feed4-layout .recommended-swipe { display: none !important; }
```

**搜索引擎**：设置 → 搜索引擎，填含 `%s` 的模板即可，例如 `https://duckduckgo.com/?q=%s`。

**保存视频**：鼠标停在视频上会出现一条小工具条，最右边的 ⬇ 把视频存进下载目录。对直链 mp4 直接下载；对 bilibili 会问它自己的接口拿到当前这一 P 的地址再下载，文件带声音、出现在下载列表里、可暂停。清晰度取当前登录身份允许的最高一档——未登录通常是 720P，有会员可以更高。只能存 bilibili 的单文件版本：只提供音视频分离流的视频会明确说存不了，而不是存一个没声音的文件。

## 已知限制

- **不支持密码管理**：没有凭据库集成，也没有自动填充
- **挂起、撤销关闭、会话恢复都只记住地址**：页面会重新加载，浏览器的后退/前进历史、未提交的表单内容、已选中的上传文件都会丢。默认最多 12 个标签同时存活，超出即挂起
- **用户脚本只提供 `GM_getValue` / `GM_setValue` / `GM_info` / `unsafeWindow`**；用到 `GM_xmlhttpRequest`、`GM_addStyle`、`GM_registerMenuCommand` 的脚本会静默失败（只在控制台留一行警告）
- **跨域 iframe、Shadow DOM 内的文字无法翻译**
- **只能装 MV3 扩展**，且扩展的 popup 气泡打不开（WebView2 没暴露该接口），只能看扩展信息
- **画布上的文字无法选中或翻译**
- **阅读模式是启发式提取**：按正文长度与链接密度打分，新闻 / 博客 / 文档站通常准确，SPA 与卡片布局的页面可能抓错区块或抓到侧栏
- **另存为只保存文档本身**：不含外链样式、脚本和图片，用浏览器打开会缺样式；跨域 iframe 与画布内容也拿不到
- **无痕标签隔离的是 cookie 与缓存**：下载的文件仍会留在磁盘上，只是不写进下载记录
- **拖出窗口的标签会新开一个进程**（与 `Ctrl+N` 同享 `UserData`，但拖出的那个关闭后不影响主窗口继续运行）
- **只在 Windows 上编译验证过**：macOS / Linux 的适配层还没写（`src-tauri/src/platform/` 里只有 `windows.rs`）

## 从源码构建

需要 Rust 1.80+ 和 Node 22。

```powershell
# 先跑能自动化的检查：单元测试、clippy、rustfmt、内部页构建、词条、硬编码文案、命令清单一致性
powershell -File scripts\check-all.ps1

cd src-tauri
cargo build --release
powershell -File ..\scripts\build-portable.ps1
```

`check-all.ps1` 用**已安装的、磁盘上真有 `cargo-clippy` / `cargo-fmt` 的那个工具链**跑这两项检查
（`rustup component list` 可能报告组件已安装而二进制缺失，脚本按文件判断），任何一项不过就失败；
一个都没有时打印 skipped，不会静默通过。

新增 IPC 命令后必须跑一次 `node scripts/gen-commands.js`：它把 `main.rs` 里的命令清单同步到
`build.rs`（ACL 生成）和 `capabilities/default.json`（本地页面授权），三份清单不再手工维护。

产物在 `dist/Mix-<version>-release.zip`。

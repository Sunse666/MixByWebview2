# Mix

一个自己用的 Chromium 内核浏览器，基于 Tauri 2 + WebView2。便携、可定制、数据全在本地。

## 快速开始

1. 解压 `Mix-0.1.0-release.zip` 到任意目录（不要放在 C 盘 Program Files）
2. 双击 `mix.exe`
3. 首次启动会在同目录生成 `UserData/`、`crx/`、`javascript/`

不需要安装、不需要管理员权限、不留注册表垃圾（除非你主动点"注册为浏览器"）。

## 目录结构

```
Mix/
├── mix.exe
├── UserData/           ← 你的所有数据
│   ├── settings.json   设置
│   ├── history.json    历史
│   ├── bookmarks.json  书签
│   ├── favicons.json   网站图标映射
│   ├── favicons/       图标本地缓存
│   ├── session.json    上次的窗口与标签
│   ├── theme.json      主题
│   ├── custom.css      自定义样式（对所有网页生效）
│   └── logs/mix.log    运行日志（出问题时看这里）
├── crx/                ← 扩展放这里（解压后的文件夹）
└── javascript/         ← 用户脚本放这里（*.user.js）
```

**备份**：设置 → 备份 → 导出配置，会打包除 WebView2 缓存外的全部数据。

## 功能

**浏览**
- 多标签 / 多窗口 / 无痕模式（紫色标识）
- 标签固定（中键或右键切换）、撤销关闭（Ctrl+Shift+T）
- 会话恢复、全屏（F11）、页内查找

**内容**
- 网页翻译（Bing 引擎，原地替换文本，不是跳转代理）
- 每站点记忆缩放、右键菜单、用户脚本
- 选中文字右键可翻译

**数据**
- 历史：分组、搜索建议、按站点筛选、图标持久化
- 书签：文件夹分类、双击改名、拖拽排序
- 下载：列表、打开、定位文件
- 网站图标：下载到本地，站点挂了也不影响

**扩展**
- 把解压好的扩展文件夹放进 `crx/`
- 扩展页可查看 WebView2 真实的加载状态、**立即启用/停用**（走 COM，不用重启）

**界面**
- 内部页面：新标签页、历史、书签、下载、扩展、设置、用户脚本
- 命令面板：Ctrl+Shift+P
- 主题：7 个颜色 + 圆角/字号，支持实时预览与导入导出
- 中英双语

**系统**
- 注册为默认浏览器（只加入 Windows 候选列表，不抢关联）
- 配置备份/恢复、自定义样式、自定义搜索引擎

## 默认快捷键

| 按键 | 动作 |
|---|---|
| Ctrl+T / Ctrl+W | 新建 / 关闭标签 |
| Ctrl+Shift+T | 恢复关闭的标签 |
| Ctrl+Tab / Ctrl+Shift+Tab | 切换标签 |
| Ctrl+L | 聚焦地址栏 |
| Ctrl+R / F5 | 刷新 |
| Ctrl+D | 收藏 |
| Ctrl+J | 下载 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小 / 重置 |
| F11 / F12 | 全屏 / 开发者工具 |
| Ctrl+Shift+P | 命令面板 |

全部可在 **设置 → 快捷键** 里改。

## 鼠标手势

按住**右键**划动，松开执行。默认映射：

| 手势 | 动作 |
|---|---|
| ← / → | 后退 / 前进 |
| ↑ / ↓ | 滚动到顶 / 到底 |
| ↑↓ | 刷新 |
| ↓↑ | 恢复关闭的标签 |
| ←→ / →← | 下一个 / 上一个标签 |
| ↑→ | 新建标签 |
| ↓← | 关闭标签 |
| ↑← | 收藏 |
| ↓→ | 下载 |

**设置 → 鼠标手势** 可改颜色、线宽、阈值、每个手势的动作、以及禁用域名。

## 超级拖拽

按住**链接 / 图片 / 选中文字**拖出去，按方向执行：

| 方向 | 默认动作 |
|---|---|
| ← | 在新标签中打开 |
| → | 搜索文本 |
| ↑ | 复制到剪贴板 |
| ↓ | 下载目标 |

**设置 → 超级拖拽** 可改阈值、提示开关、四个方向的动作（12 种可选）。

## 扩展与用户脚本

**扩展**：解压后的文件夹放进 `crx/`，扩展页会显示。支持 MV3。

**用户脚本**：`javascript/` 里放 `*.user.js`，支持 `@name` / `@match` / `@run-at`。用户脚本页可启用/停用。

## 自定义

**主题**：设置 → 主题文件，改颜色、圆角、字号，可导出 `theme.json` 分享。

**自定义样式**：设置 → 外观 → 编辑自定义样式，写 CSS 会应用到所有网页（重启生效）。

```css
/* 例子：去掉 B 站首页的推荐位 */
.bili-feed4-layout .recommended-swipe { display: none !important; }
```

**搜索引擎**：设置 → 搜索引擎，填含 `%s` 的模板即可，例如 `https://duckduckgo.com/?q=%s`。

## 已知限制

这些是 WebView2 的边界，不是 bug：

- **不支持扩展弹窗和徽章**：宿主拿不到 `chrome-extension://` 页面
- **不支持密码管理**：没有凭据库集成，也没有自动填充
- **跨域 iframe、Shadow DOM 内的文字无法翻译**
- **只能装 MV3 扩展**
- **画布（canvas）上的文字无法选中或翻译**

## 从源码构建

需要 Rust 1.80+ 和 Node 22。

```powershell
cd src-tauri
cargo build --release
powershell -File ..\scripts\build-portable.ps1
```

产物在 `dist/Mix-<version>-release.zip`。

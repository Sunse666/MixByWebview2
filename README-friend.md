# Mix — quick start

1. Unzip anywhere you can write to (not Program Files).
2. Run `Mix.exe`. Settings, cache and logs stay in `UserData\` next to it.
3. Extensions: drop `.crx` files into `crx\`, then restart.
4. Userscripts: drop `.user.js` files into `javascript\`, then restart.
5. Move or back up the whole folder — everything travels with it.

Unsigned build: on Windows click "More info -> Run anyway" if SmartScreen complains.
